# Vite + React + TypeScript + GSAP

Полноценный npm-проект. Контент и структура перенесены из `2-62.html`; пустые секции фильтруются в `src/main.tsx`.

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

## Предпросмотр сборки

```bash
npm run preview
```

Основные файлы:

- `src/main.tsx` — React-компоненты и GSAP-анимации.
- `src/styles.css` — светлый минималистичный дизайн, адаптив, hover/scroll-анимации.
- `src/data/content.ts` — данные, извлечённые из HTML.
